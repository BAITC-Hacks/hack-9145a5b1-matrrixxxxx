# Career Quest — границы MVP

**Статус:** draft, требуется подтверждение владельцем продукта перед разработкой core backend.

## Рекомендуемое решение

Career Quest — внутренний сервис развития сотрудников. Его задача — помочь сотруднику выбрать и пройти подтверждаемый путь развития, а HR — управлять дефицитами компетенций и программой активностей.

Это **не** recruitment-система и не публичная площадка мероприятий. Регистрация кандидатов, отклики на вакансии, ATS-пайплайн и обработка заявок не входят в первый MVP.

## Почему решение нужно сейчас

Текущий UI и README описывают карьерный навигатор: skills, grade, readiness и development activities. Одновременно незакоммиченный `server.js` реализует Telegram-напоминания о мероприятиях. Без единой модели домена эти две части нельзя безопасно объединить: не определены пользователь, права, источник событий и жизненный цикл активности.

## Пользователи и роли MVP

| Роль | Цель | Основные права |
| --- | --- | --- |
| Employee | Выбрать и пройти маршрут развития | Смотреть свой профиль, записываться на активности, отправлять evidence |
| Manager | Подтверждать практический результат команды | Смотреть прямых подчинённых, подтверждать/возвращать evidence |
| HR | Управлять программой развития | Создавать и публиковать активности, назначать аудитории, смотреть агрегированную аналитику |
| Admin | Управлять правилами и доступами | Управлять пользователями, ролями, skill taxonomy, role matrices и audit log |

## Главный пользовательский сценарий

1. Employee входит через корпоративный SSO.
2. Видит свой профиль, карьерную цель, skill gaps и объяснимую рекомендацию.
3. Открывает activity, записывается и при необходимости подключает напоминания.
4. Завершает activity и прикладывает evidence.
5. Manager или HR подтверждает результат.
6. Сервис записывает progress event, пересчитывает readiness и показывает следующий шаг.

## Границы первого релиза

### Входит

- SSO/mock authentication с RBAC;
- persisted employee profile, skills, career goal и progress history;
- каталог и CRUD development activities;
- enrollment, completion, evidence и review workflow;
- базовый HR-список сотрудников и skill-gap analytics;
- notification preference и Telegram reminder как дополнительный канал;
- audit log критичных изменений.

### Не входит

- ATS, вакансии, отклики кандидатов, интервью и hiring pipeline;
- публичный рейтинг сотрудников;
- автоматическое кадровое решение без человека;
- полноценная LMS и платёжные сценарии;
- свободный LLM-чат без утверждённой базы знаний и privacy controls.

## Domain vocabulary

| Термин | Значение |
| --- | --- |
| Activity | Развивающая активность: курс, практикум, менторство, проект или workshop |
| Enrollment | Запись сотрудника на activity |
| Evidence | Ссылка/файл/комментарий, подтверждающий применение навыка |
| Progress event | Неизменяемая запись о подтверждённом изменении навыка или статусе activity |
| Role matrix | Требования к skill levels для роли и grade |
| Recommendation | Версионированное предложение следующего шага; не кадровое решение |

## Критерий готовности следующей задачи

Перед созданием API и БД владелец продукта подтверждает, что Career Quest — сервис развития сотрудников с описанными ролями и что Telegram-напоминания привязаны к `Enrollment`/`Activity`, а не к самостоятельной сущности мероприятий.
