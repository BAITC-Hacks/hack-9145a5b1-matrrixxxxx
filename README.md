# Career Quest

Интерактивный MVP AI-навигатора развития сотрудников для HackAlem AI.

## Возможности

- карта навыков и готовность к следующему грейду;
- многофакторные рекомендации с объяснением;
- симуляция и фиксация результата активности;
- загрузка проверочного JSON-профиля;
- HR-дашборд по дефицитам компетенций;
- локальная работа без внешнего API.

## Локальный запуск

Откройте `dist/index.html` в браузере или запустите любой статический HTTP-сервер из папки `dist`.

## Формат загружаемого профиля

```json
{
  "employee_id": "E0028",
  "role": "Backend Engineer",
  "grade": "Middle",
  "tenure_months": 52,
  "skills": {
    "SK_PYTHON": 3,
    "SK_SYSTEM_DESIGN": 2,
    "SK_PUBLIC_SPEAKING": 2
  }
}
```
