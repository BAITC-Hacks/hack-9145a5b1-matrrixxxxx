# Career Quest

Career Quest — интерактивный MVP объяснимого AI-навигатора развития сотрудников, созданный для HackAlem AI. Продукт связывает текущие навыки сотрудника, требования следующего грейда, историю активностей и доступные форматы развития в единый персональный маршрут.

**Публичная версия:** https://career-quest-hackalem-2026.rsovovov.chatgpt.site

## Что реализовано

- профиль сотрудника и карта навыков;
- расчёт готовности к следующему грейду;
- многофакторные рекомендации с прозрачным скорингом;
- симуляция результата и обновление прогресса;
- загрузка новых проверочных JSON-профилей;
- альтернативные шаги развития и AI-навигатор;
- HR-дашборд по дефицитам компетенций;
- экспорт персонального плана и HR-отчёта;
- адаптивный интерфейс для компьютера и телефона;
- автономная работа без внешнего API.

## Архитектура MVP

Проект реализован как статическое одностраничное приложение. Алгоритм рекомендаций и демонстрационные данные выполняются в браузере. Благодаря этому MVP запускается без сервера, базы данных, секретов и внешних сервисов — удобно для воспроизводимой хакатонной демонстрации.

```text
Профиль + навыки + история
          ↓
   Расчёт skill gaps
          ↓
 Многофакторный скоринг
          ↓
Топ-рекомендации + объяснение
          ↓
Симуляция прогресса / HR-срез
```

## Локальный запуск

Откройте `index.html` в браузере. В исходном checkout Sites страница находится в `dist/index.html`.

Для локального HTTP-сервера:

```bash
python -m http.server 4173
```

После этого откройте `http://localhost:4173`.

## Формат загружаемого профиля

```json
{
  "employee_id": "E0028",
  "role": "Backend Engineer",
  "grade": "Middle",
  "tenure_months": 52,
  "skills": {
    "SK_PYTHON": 3,
    "SK_SYSTEM_DESIGN": 2,
    "SK_PUBLIC_SPEAKING": 2
  }
}
```

Поле `skills` может содержать дополнительные идентификаторы навыков. Приложение валидирует обязательные поля и строит рекомендацию без привязки к конкретному `employee_id`.

## Безопасность и приватность

- используются только синтетические профили;
- данные загруженного файла обрабатываются локально в браузере;
- данные не отправляются во внешние API;
- продукт не принимает кадровые решения и не формирует публичные рейтинги сотрудников.

## Развитие после MVP

Production-версия потребует корпоративной аутентификации, разграничения ролей Employee/Manager/HR, серверного recommendation engine, защищённого хранения данных, аудита решений, интеграций с HRIS/LMS и мониторинга качества рекомендаций.
